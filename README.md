# 키즈브레인 플래시암산 (안드로이드 앱)

**FLEDU 블루투스 전자주판**과 연결해서 쓰는 주산·암산 학습 앱입니다.
앱은 FLEDU 전자주판이 연결되어 있어야 메뉴가 열립니다.

## 내려받기
오른쪽 **Releases**의 최신 버전에서 `kizbrain-flash-버전.apk` 파일을 휴대폰으로 내려받으세요.

## 설치 방법
1. 휴대폰에서 APK 파일을 엽니다.
2. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켭니다.
3. Play 프로텍트 안내가 나오면 **무시하고 설치**(또는 세부정보 → 설치)를 누릅니다.
4. 설치가 끝나면 **블루투스를 켜고** 전자주판 전원을 켠 뒤 앱을 엽니다.

## 업데이트
새 버전이 나오면 앱이 "새 버전이 있습니다"라고 알려 줍니다. [받기]를 눌러 새 APK를 설치하면 학습 기록은 그대로 남습니다.

## 지원 환경
- 안드로이드 8 이상 휴대폰·태블릿 (가로 화면)
- FLEDU 전자주판 펌웨어 V2 권장 (V1도 사용 가능, 일부 기능 제한)
