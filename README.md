# 키즈브레인 플래시암산 (안드로이드 앱)

**FLEDU 블루투스 전자주판**과 연결해서 쓰는 주산·암산 학습 앱입니다.
앱은 FLEDU 전자주판이 연결되어 있어야 메뉴가 열립니다.

<img src="install-qr.png" width="180" alt="설치 페이지 QR 코드">

휴대폰 카메라로 QR 코드를 찍거나 아래 주소를 여세요.
**https://github.com/kizbrain/kizbrain-app/releases/latest**

---

## 설치 방법 (처음 한 번)

### 1. APK 내려받기
1. 위 주소(또는 QR)를 휴대폰 **크롬**으로 엽니다.
2. 아래쪽 **Assets**에서 **`kizbrain-flash-버전.apk`**(예: kizbrain-flash-1.0.0.apk)를 누릅니다.
3. "이 유형의 파일은 기기를 손상시킬 수 있습니다"가 나오면 **[다운로드]**를 누릅니다.

### 2. 내 파일에서 설치하기
다운로드가 끝나도 설치 화면이 바로 뜨지 않을 수 있습니다. 그럴 때는 직접 찾아서 엽니다.
1. **내 파일**(삼성) 또는 **파일 관리자** 앱을 엽니다.
2. **다운로드** 폴더 → **`kizbrain-flash-버전.apk`**를 누릅니다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **[설정] → "이 출처 허용"을 켜고** 뒤로 돌아갑니다.
4. **[설치]**를 누릅니다.
5. **Play 프로텍트** 안내가 나오면 **[세부정보 더보기] → [무시하고 설치]**를 누릅니다.
   (플레이스토어를 거치지 않은 앱이라 나오는 일반 안내입니다)

### 3. 처음 실행
1. 휴대폰 **블루투스를 켭니다.**
2. 전자주판 **전원을 켭니다.**
3. 앱을 열고 이용 약관에 동의 → 목록에서 주판을 고르면 연결됩니다.

### 설치가 안 될 때
- **"앱이 설치되지 않았습니다"**: 예전에 받은 시험용(테스트) 앱이 남아 있습니다. 설정 → 애플리케이션에서 **키즈브레인 플래시암산**을 지우고 다시 설치하세요. (기존 **키즈브레인** 앱은 별개라 지우지 않아도 됩니다)
- **"자동 차단에 의해 차단됨"**(삼성): 설정 → 보안 및 개인정보 보호 → **자동 차단**을 잠시 끄고 설치한 뒤 다시 켜세요.
- **"관리자가 차단"**: 회사·학교·자녀 보호로 관리되는 휴대폰입니다. 관리자에게 허용을 요청하세요.

## 업데이트
새 버전이 나오면 앱이 **"새 버전이 있습니다"**라고 알려 줍니다. [받기]를 눌러 같은 방법(내 파일에서 설치)으로 설치하면 **학습 기록은 그대로** 남습니다. 앱을 지울 필요가 없습니다.

## 지원 환경
- 안드로이드 8 이상 휴대폰·태블릿 (가로 화면)
- FLEDU 전자주판 펌웨어 V2 권장 (V1도 사용 가능, 일부 기능 제한)
